# 团队空间 · 环境Agent 控制台 — 功能操作清单

技术栈：Vue 3 + Vite + Vue Router + Pinia，数据持久化在浏览器本地存储层（`src/services/storage.js` 与 `src/services/persist.js` 统一读写，刷新后数据保留）。

界面为深色控制台风格，左侧一级导航，右上角品牌区，全站统一的表格 / 抽屉 / 弹窗 / 提示交互。

---

## 0. 全局操作

| 编号 | 操作 | 说明 |
| --- | --- | --- |
| G-01 | 导航切换 | 左侧菜单一级跳转，当前项高亮，页面标题同步顶部栏 |
| G-02 | 侧栏折叠 | 收起／展开侧栏，仅保留图标 |
| G-03 | 当前用户信息 | 底部展示登录账号与角色，点击查看账号面板 |
| G-04 | 全局搜索框 | 各列表页关键字实时过滤（名称／编码／描述） |
| G-05 | 分页与每页条数 | 列表统一分页，可切换 10／20／50 条 |
| G-06 | 操作提示 | 新增／保存／删除等操作后右上角浮层提示 |
| G-07 | 危险操作确认 | 删除、重置、清空类操作二次确认 |
| G-08 | 数据持久化 | 全部业务数据写入本地存储，重新打开自动恢复 |
| G-09 | 审计留痕 | 关键写操作自动写入系统管理的操作日志 |
